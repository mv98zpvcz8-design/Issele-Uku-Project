# Admin Guide

**Status: not yet built.** The admin system is Phase 6 of ROADMAP.md. This
file will become a plain-language guide for a non-technical administrator
covering:

- Logging in
- Creating and editing archive records, people, places, events, monarchs
  and sources
- Uploading media and setting copyright status correctly
- Moving a record through the DRAFT → RESEARCH → REVIEW → APPROVED →
  PUBLISHED workflow
- Marking a record RESTRICTED or sensitive
- Reviewing submissions from the public submission form
- Managing oral history consent and publication permission

It will be written and screenshotted against the real admin UI once
Phase 6 is built — writing it earlier would risk describing a UI that
doesn't match what's shipped.
